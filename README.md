# Landing Page

## Versión v1.0

Esta versión merece ser marcada como `v1.0` porque el landing ya tiene su estructura principal terminada y representa una versión estable del proyecto. Esta versión reúne los cambios realizados hasta el momento y permite identificar fácilmente el estado actual del proyecto.

## Git stash

`git stash` sirve para guardar temporalmente los cambios que tenemos en el proyecto sin hacer un commit. De esta manera podemos cambiar de rama o realizar otras acciones sin perder los cambios que todavía no queremos guardar definitivamente.

## Git tag

`git tag` sirve para marcar una versión específica del proyecto. En este caso se utilizó `v1.0` para identificar la versión actual y tener una referencia de esta etapa del landing.
